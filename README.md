# ShiftPay

**Практикалық жұмыс №3 · Жүйеге кіру беті**  
Бахриден Жанат Бөлтірікұлы · БҚ-2503 · Astana IT University колледжі

ShiftPay — жұмыс ауысымдарын тіркейтін, жұмыс уақытын және ақысын есептейтін қазақша десктоп қолданба. Тіркелу, жүйеге кіру және жеке ауысымдар журналы PyQt5 интерфейсінде жұмыс істейді.

## macOS жүйесінде іске қосу

Компьютерде Python 3.11 немесе 3.13 және PostgreSQL 17 болуы керек. VS Code арқылы осы `ShiftPay_Desktop` бумасын ашыңыз. VS Code терминалында:

```bash
bash start.command
```

Скрипт Python ортасын дайындап, PyQt5 орнатылғанын тексереді және қолданбаны ашады. Алғаш рет тіркелгенде немесе кіргенде қолданба PostgreSQL кластерін жобаның `.local/postgres` бумасында автоматты түрде құрады. Жоба жеке Unix сокетін пайдаланады, сондықтан Homebrew қызметін бөлек іске қосу немесе PostgreSQL құпиясөзін енгізу қажет емес. Алғашқы әрекет бірнеше секунд алуы мүмкін.

PostgreSQL 17 орнатылмаған болса:

```bash
brew install postgresql@17
```

VS Code-та F5 арқылы іске қосу үшін алдымен `bash start.command` пәрменін бір рет орындаңыз. Содан кейін VS Code ішіндегі Python және Python Debugger кеңейтімдерімен `ShiftPay · іске қосу` конфигурациясын таңдаңыз. Интерпретатор ретінде `.venv/bin/python` пайдаланылады.

PostgreSQL басқа бумада орнатылса, `SHIFTPAY_PG_BIN` айнымалысына `psql`, `initdb`, `pg_ctl` файлдары тұрған **bin** бумасының жолын беруге болады. Бұрыннан бар PostgreSQL базасын қолдану үшін `SHIFTPAY_DATABASE_URL` орнатыңыз. Оның пайдаланушысында `shiftpay` схемасын құру және қолдану құқығы болуы керек.

Қолданбаның жеке PostgreSQL процесін тоқтату үшін терезені жауып, `.venv/bin/python database.py` пәрменін орындаңыз. Келесі кіру кезінде процесс қайта іске қосылады.

## Қорғауда көрсету

1. **Тіркелу** бетіне өтіп, логин мен кемінде 8 таңбадан тұратын құпиясөз енгізіңіз. Құпиясөзді қайталаңыз.
2. **Кіру** бетінде бос өрісті немесе қате құпиясөзді көрсетіңіз. Ескерту шығып, басты бет жабық қалады.
3. Дұрыс логин және құпиясөзбен кіріңіз. Жеке журнал мен айлық жиынтық ашылады.
4. **Ауысым қосу** түймесін басыңыз. Мысалдағы 16:00–01:00, 30 минут үзіліс және 1 100 ₸/сағат параметрлері 8 сағат 30 минутты және 9 350 ₸ сомасын береді.
5. Ауысымды сақтап, журналда таңдаңыз. **Төленді деп белгілеу** түймесінен кейін айлық жиынтық өзгереді.

## Дерекқор құрылымы

| Кесте | Мазмұны |
| --- | --- |
| `shiftpay.users` | Жеке идентификатор, бірегей логин, salt қосылған scrypt хеші және тіркелген уақыт |
| `shiftpay.shifts` | Ауысым идентификаторы, пайдаланушы идентификаторы, уақыт, үзіліс, төлем сомасы және мәртебе |

`schema.sql` файлы кестелер мен шектеулерді сипаттайды. Құпиясөздің өзі сақталмайды. Әр пайдаланушының ауысымдары оның аккаунт идентификаторы бойынша алынады.

## Жоба файлдары

- `main.py` — тіркелу, кіру, журнал және ауысым формасы.
- `database.py` — PostgreSQL іске қосу, дерекқормен байланыс және құпиясөз хеші.
- `shifts.py` — ауысым ұзақтығын, еңбекақыны және айлық жиынтықты есептеу.
- `style.qss` — интерфейс стилі.
- `screenshots/` — кіру және тіркелу терезелерінің скриншоттары.

Telegram боты телефоннан ауысымды есептеуге арналған қосымша құрал ретінде бөлек іске қосылады. Десктоп қолданбасының аккаунттары мен журналы PostgreSQL-де сақталады.
